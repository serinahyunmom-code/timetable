# 학년 시간표 자동 배치

3·4·5·6학년 학급 시간표를 자동으로 배치하는 웹 앱이에요.

- 학년별 반 수, 과목, 실시 시수 설정
- 고정 수업을 먼저 찍고 나머지 자동 배치
- 전담 과목은 선생님 가능 시간 안에서 반끼리 겹치지 않게 배치
- 엑셀 파일 저장 / 엑셀 붙여넣기용 복사

입력한 내용은 사용하는 브라우저의 `localStorage`에만 저장돼요. 서버 저장·계정·AI 분석·외부 클라우드 동기화가 없어요. 학생 이름·상담 기록은 입력하지 말고, 선생님 이름 대신 과목별 호칭을 권장해요. 공용 기기에서는 **저장된 모든 시간표 삭제**를 눌러 주세요. 내려받은 엑셀 파일은 별도 관리해야 해요.

## 실행과 배포

Node.js 24 이상의 지원되는 최신 보안 패치를 사용하세요. 설치할 npm 의존성은 없습니다.

```sh
npm start
npm test
```

기본 주소는 `http://localhost:8080`이고 Railway에서는 제공된 `PORT`를 사용합니다. `Dockerfile`은 실행에 필요한 정적 자산과 서버만 복사하며 일반 사용자 권한으로 실행합니다. 상태 확인은 `/healthz`입니다.

엑셀 파일은 브라우저에서 외부 라이브러리 없이 생성합니다. 모든 사용자 입력은 XLSX의 문자열 셀로 저장하고, 붙여넣기용 데이터는 수식으로 해석될 수 있는 접두어를 보호합니다. 외부 폰트·CDN 스크립트·추적 도구를 불러오지 않습니다.

보안 검토 범위와 수정 내역은 [보안 검토 기록](SECURITY_REVIEW.md)을 확인하세요. 새 코드 변경 후에는 검사·테스트를 다시 실행해야 합니다.
